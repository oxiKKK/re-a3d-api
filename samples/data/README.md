# Sample media

The samples and comparison tests read these files. They are not distributed
with this repository; place your own copies here under these names.

| file | used by |
| --- | --- |
| `heli.wav` | samples, `m1probe`, A/B and audio comparison tests |
| `clap_test.wav`, `linn1.wav`, `linn48.wav` | samples and SceneRooms comparison tests |
| `FILE0038.WAV` | `volsrc` sample |
| `Scooter.mp3` | MP3 decoder test |
| `Spoken_Chan1.ac3` | AC-3 decoder test |
